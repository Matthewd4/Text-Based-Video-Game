# Cornelius V. Irus's Haunted Hospital
This is my first ever text-based video game I created!
I wrote this in Python within the IDE PyCharm. I used an inventory system, where you are attempting to fill your inventory with 6 items in various rooms that will help you defeat the final boss to disinfect the hospital. I also wrote pseudocode and built storyboards during the development. 

# How To Play
To play this video game, you must have python installed on your system. Ensure you have python installed by opening a terminal and typing 'python -- version' or 'python3 --version'. If it shows a version number you are good to go, if not, download Python from python.org and install it.
